# Skill写作对照样例

材料版本v1.0.28。用途：同一份虚构TXT、同一任务，分别不开启Skill和明确开启两章规范，各真实运行一次。[返回样例入口](../README.md)。

- [原资料TXT](../../results/inputs/EX-001/星桥演示设备借用规则_v1.0.0.txt)：沿用EX-001原文件，包含真实测试预期所依据的虚构规则，不是生产制度。
- [共同任务TXT](request_v1.0.28.txt)：两组字节相同的中文需求，等待程序需求提示后输入，不是PowerShell命令。
- [运行前预期MD](expected_v1.0.28.md)：两组共同要求、Skill专属要求和判定边界，运行前已冻结。
- [skill.json](skill.json)和[SKILL.md](SKILL.md)：最小可加载规范，只有两章、file来源、全文300字；不包含3天/2工作日等答案事实，也没有模板或附加参考文件。
- [实际结果](../../results/latest_run/README.md)：两份原始Word及页面、正确和未满足项。

基线使用独立空DOCUMENT_SKILLS_DIR且不传--skill；规范组使用只含本包的独立目录并显式--skill包路径。两组输出独立，本机实际驱动在忽略的运行目录；团队可在固定候选的公开控制台按相同条件复现，不复制密钥或本机配置。

TXT/MD/JSON按UTF-8保存。Skill配置版本1和资料/成果v1.0.0是各自标识，不随测试管理文档版本递增。本样例不抵扣原36条正式用例整体验收。
