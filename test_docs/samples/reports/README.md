这里记录样例准备阶段已经核对什么，以及12项CP用例的初始执行状态。

| 文件或子目录 | 用途与格式 |
| --- | --- |
| [preparation_report_v1.0.15.md](preparation_report_v1.0.15.md) | 给人看的准备报告：已检查项和未验证范围；MD |
| [preparation_checks_v1.0.15.json](preparation_checks_v1.0.15.json) | 机器可读的准备检查回执；JSON，不能代替模型成果验收 |
| [execution_queue_v1.0.15.md](execution_queue_v1.0.15.md) | 12项用例的初始执行队列；MD表格 |

**先怎么用：**先看准备报告。实际执行后记录真实状态与证据，失败也要保留；不要把“准备完成”写成业务通过。

**注意：**JSON里的计数属于当时准备检查，不会因新增README自动重算。正式36条、12项CP和两项历史探索分别记录。
