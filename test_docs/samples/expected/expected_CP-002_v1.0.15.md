版本：v1.0.15。制定阶段：运行前。业务状态：未执行。用例：[查看操作](../cases/case_CP-002_v1.0.15.md)。

## 逐项核对

- [ ] E2例行检查频率为每15天一次，来源第四章，不采用T1每10天或L8每月。
- [ ] E2演示异常发现后4小时内向演示协调员报告，来源第十章；不可写成2小时或1小时。
- [ ] E2校验记录保留75天，来源第十七章；不串入90天、30天、20天或便条7天。
- [ ] 三个字段都明确指向E2，接收角色不能误写成资料复核员或温度演示员。
- [ ] 只回答三个字段，不把其他设备或数量当本例必需内容；不编造来源。
- [ ] 正文≤160个非空白字符，不含文档标题、含字段名称；无表格、宋体黑色，输出版本v1.0.15。

## 判定边界

- 长TXT只证明本例读取/检索与写作场景，不等同于摘要DAG或图谱问答已执行。

输入基准与哈希见[准备清单](../manifest_v1.0.15.json)及[Word结构基准](baselines_v1.0.15.json)。结构快照只描述输入，不是预期输出，更不是实际输出。

未检查项保持未检查；生成式内容可用等义表达，但数字、对应关系和否定条件必须逐项对照。仅结构核对不能代替Word页面实看；字体和颜色也要检查实际继承。发现失败先保留完整材料，再确认是否为原产品缺陷、接入适配、环境问题或待确认需求。
