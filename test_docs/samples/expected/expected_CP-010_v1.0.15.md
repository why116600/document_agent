# CP-010 预期检查清单 v1.0.15

版本：v1.0.15。制定阶段：运行前。业务状态：未执行。用例：[查看操作](../cases/case_CP-010_v1.0.15.md)。

## 逐项核对

- [ ] 包括标题、语料标识、正文、表头和各格的逐元素文字完全一致，不只比较总字数。
- [ ] 文档标题18磅居中，两个一级标题16磅，其他正文和所有表格文字12磅。
- [ ] 所有段落（含表格段落）段前0磅、段后6磅，1.5倍行距；检查实际样式继承与直接格式。
- [ ] 全部中文宋体、所有文字黑色；不使用不同字体或彩色文字作为输入差异。
- [ ] 表格保持3行3列，5份/3份/8份及45天的对应关系逐字不变。
- [ ] 原稿哈希不变；结果另存并实际打开检查页面。此输入字号段距不同是有意设置的测试条件，不应提前规范成预期。

## 判定边界

- 只覆盖普通正文和简单表格，不声称复杂图片/公式/分节保真已验证。

输入基准与哈希见[准备清单](../manifest_v1.0.15.json)及[Word结构基准](baselines_v1.0.15.json)。结构快照只描述输入，不是预期输出，更不是实际输出。

未检查项保持未检查；生成式内容可用等义表达，但数字、对应关系和否定条件必须逐项对照。仅结构核对不能代替Word页面实看；字体和颜色也要检查实际继承。发现失败先保留完整材料，再确认是否为原产品缺陷、接入适配、环境问题或待确认需求。
