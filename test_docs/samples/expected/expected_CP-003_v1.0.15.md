## 逐项核对

- [ ] 采用新规则4天、提前3个工作日，不采用旧规则9天和提前1个工作日。
- [ ] 审批人为演示资料员且先确认可用，不能沿用旧版演示管理员。
- [ ] 归还外观检查并登记时间两项齐全，不只沿用旧版登记时间。
- [ ] 不把两份资料折中为一个新的期限或自行选择混合规则；本次优先级已在请求中明确。
- [ ] 不因费用未说明而写成免费或免押金，不增加实际人员。
- [ ] 正文≤180个非空白字符，不含文档标题、含章节标题；宋体黑色、无表格，新版标题和输出版本v1.0.15。

## 判定边界

- 优先级由本子例明确指定，不代表系统已解决未指定优先级的知识库冲突。旧输入文件保留真实v1.0.14版本。

输入基准与哈希见[准备清单](../manifest_v1.0.15.json)及[Word结构基准](baselines_v1.0.15.json)。结构快照只描述输入，不是预期输出，更不是实际输出。

未检查项保持未检查；生成式内容可用等义表达，但数字、对应关系和否定条件必须逐项对照。仅结构核对不能代替Word页面实看；字体和颜色也要检查实际继承。发现失败先保留完整材料，再确认是否为原产品缺陷、接入适配、环境问题或待确认需求。
