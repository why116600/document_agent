# CP-006 预期检查清单 v1.0.15

版本：v1.0.15。制定阶段：运行前。业务状态：未执行。用例：[查看操作](../cases/case_CP-006_v1.0.15.md)。

## 逐项核对

- [ ] 输入必须是实际零字节TXT，不是含一个换行或空白提示句的文件。
- [ ] 准确说明资料为空或没有有效规则，不伪称已经读到了具体制度。
- [ ] 不编造借用天数、费用、角色、适用范围等事实。
- [ ] 不通过知识库、其他文件或外部资料偷偷补齐输入，保留真实尝试。
- [ ] 实际是否生成文件、返回何种退出码分别记录；本次请求希望不生成Word，但原TC-08未统一规定该分支必须非零或绝不产文件，作为新增待确认口径，不据此自动登记原项目缺陷。
- [ ] 记录实际结果和错误，未执行前不填失败或通过；原输入运行前后仍为零字节且哈希一致。

## 判定边界

- 安全硬项是明确资料不足、不编造、不虚称已读和不偷偷补齐；具体文件生成与退出码口径需复核。

输入基准与哈希见[准备清单](../manifest_v1.0.15.json)及[Word结构基准](baselines_v1.0.15.json)。结构快照只描述输入，不是预期输出，更不是实际输出。

未检查项保持未检查；生成式内容可用等义表达，但数字、对应关系和否定条件必须逐项对照。仅结构核对不能代替Word页面实看；字体和颜色也要检查实际继承。发现失败先保留完整材料，再确认是否为原产品缺陷、接入适配、环境问题或待确认需求。
