## 逐项核对

- [ ] 仅限内部演示，不向外部借出；不得转借这两个限制保留，不能改成允许转借。
- [ ] 总18套=甲柜11套+乙柜7套；数字及柜子对应关系保留，不可只检查18/11/7是否出现。
- [ ] 提前2个工作日申请，每次最多3天，记录保留60天。
- [ ] 演示管理员确认可用后批准，申请不等于自动批准；归还需外观检查和登记时间。
- [ ] 未说明收费/押金/逾期处罚，允许自然改写为资料未规定，不能据此推导免费或无处罚。
- [ ] 三个主题仍在，无表格；明确口径的正文非空白字符≤450，宋体黑色；另存且原稿哈希不变。

## 判定边界

- 允许措辞变化，不能用全文相等或相似度代替逐事实验收。

输入基准与哈希见[准备清单](../manifest_v1.0.15.json)及[Word结构基准](baselines_v1.0.15.json)。结构快照只描述输入，不是预期输出，更不是实际输出。

未检查项保持未检查；生成式内容可用等义表达，但数字、对应关系和否定条件必须逐项对照。仅结构核对不能代替Word页面实看；字体和颜色也要检查实际继承。发现失败先保留完整材料，再确认是否为原产品缺陷、接入适配、环境问题或待确认需求。
