## 逐项核对

- [ ] 输入只有一、预约，二、使用，三、归还，不存在五、费用管理；正文也不存在原词免费。
- [ ] 明确说明找不到目标章节/原词，不误称已替换成功。
- [ ] 不得把相似章节或全文当替代目标，不新编费用规则。
- [ ] 原输入哈希不变，已有三个章节、2小时、1个工作日、8人和门禁限制保持。
- [ ] 按本次请求不应产生伪成功的替代Word；若存在失败状态与文件保留的实现差异，先保留实际结果并复核口径。
- [ ] 记录实际退出状态、耗时和是否需人工中断；不捏造固定秒数SLA，不以人工截止直接宣布超时缺陷。

## 判定边界

- 只覆盖明确不存在章节和原词，不覆盖同名章节歧义或元素下标边界。

输入基准与哈希见[准备清单](../manifest_v1.0.15.json)及[Word结构基准](baselines_v1.0.15.json)。结构快照只描述输入，不是预期输出，更不是实际输出。

未检查项保持未检查；生成式内容可用等义表达，但数字、对应关系和否定条件必须逐项对照。仅结构核对不能代替Word页面实看；字体和颜色也要检查实际继承。发现失败先保留完整材料，再确认是否为原产品缺陷、接入适配、环境问题或待确认需求。
