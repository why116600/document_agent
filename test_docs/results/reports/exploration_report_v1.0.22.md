| 指定变化 | 原稿 | 新版 | 当前文件对照 |

| 提前申请 | 1个工作日 | 2个工作日 | 旧词出现 1 次，新版已完成 1 次替换 |

两版均有 10 个正文段落、10 个文字 run。变化仅位于标题、借用期限和预约要求三个段落；其他正文逐字符一致。10 组完整 run 格式属性相同，宋体、黑色、字号和粗体设置保持。原稿当前仍存在并保留旧内容，但缺少运行前哈希，不能证明当时绝未写入原稿。

**OBS-002：额外出现空页眉、空页脚结构。** ZIP 部件数从 17 变为 19，新增 `word/header1.xml` 和 `word/footer1.xml`，各 1293 字节、各 1 个空段落；正文没有新增可见页眉页脚文字。对应页面引用、关系及内容类型声明也随之增加。

共同部件中有 3 个变化：`word/document.xml`、`word/_rels/document.xml.rels`、`[Content_Types].xml`；其余 14 个共同部件字节一致。排除新增的两个页眉页脚引用后，新文档语义 XML 树与旧文档仅作三项指定替换所得预期相同。

因此能说“三项替换正确，其他正文和 run 格式保持”，**不能说整个文件仅有三处变化或所有版式完全未变**。空部件的页面影响尚未独立视觉核对，其需求归属和基线影响还需确认；本报告保留原成果，不修正或隐藏该现象，不直接新增确认缺陷。

本简单样例没有正文表格、图片、公式、域或超链接，不能据此宣称复杂 Word 对象保真已通过。
