## 2. 原任务要求

只进行下列三组替换：

| 原文字 | 目标文字 |
| --- | --- |
| 7天 | 3天 |
| 1个工作日 | 2个工作日 |
| v1.0.0 | v1.0.1 |

其他文字、章节与格式保持不变。另存为 `设备借用办法_v1.0.1.docx`，不覆盖输入 `设备借用办法_v1.0.0.docx`。
